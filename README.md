# Kampüs Etkinlikleri

Aynı repoda iki uygulama:

| Klasör | Ne | Adres |
|---|---|---|
| `frontend/` | React + Vite arayüzü | http://localhost:5173 |
| `backend/` | Node + Express REST API | http://localhost:3000 |

## Frontend

```bash
cd frontend
npm install
npm run dev
```

Detaylar ve route listesi: [frontend/README.md](frontend/README.md)

## Backend

```bash
cd backend
npm install
npm run dev
```

REST sözleşmesi ve testler: [backend/README.md](backend/README.md)
